# AI 自动化商品图栏目

## 范围

在现有作品集“精选作品”中新增第 6 个栏目，用于展示 AI 自动化商品图工作流成果。

## 内容

- 栏目名称：AI 自动化商品图
- 英文类型：AI AUTOMATED E-COMMERCE
- 简介：展示从实拍证据读取、商品详情页生成、质量检查到批量交付的自动化商品图流程。
- 素材：用户提供的 3 张工作流与商品详情图截图。

## 交互

- 首页卡片显示 3 张素材的组合预览。
- 点击卡片打开项目弹窗。
- 弹窗中展示 3 张完整图片；每张图片均可点击放大，并复用现有图片查看器。
- 键盘、触屏和移动端布局沿用现有项目卡片与画廊行为。

## 验收标准

- [x] “精选作品”出现编号 06 的“AI 自动化商品图”栏目。
- [x] 首页预览能正常加载 3 张提供的图片。
- [x] 点击栏目能打开弹窗并浏览 3 张图片。
- [x] 点击任意图片能进入现有放大查看界面。
- [x] 图片包含有意义的中文替代文本并启用延迟加载。
- [x] 现有 5 个栏目、导航、简历与联系方式不受影响。
- [x] 桌面端和手机端没有横向溢出，`npm run build:pages` 构建成功。
